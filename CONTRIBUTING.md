# Contributing to type-miss

Thanks for helping make typo recovery more useful and less interruptive.

## Report a case

Open an issue with:

1. The typo-containing text.
2. The intended wording.
3. Only the context needed to disambiguate it.
4. Whether the assistant should correct silently, state an assumption, or ask.

Use invented or public examples. Remove names, private messages, credentials, customer data, and other personal or confidential information.

## Propose a change

- Keep the skill portable and instruction-only unless a dependency clearly solves a real limitation.
- Include cases where the unusual wording is intentional, not only cases that should be corrected.
- Preserve the user's requested meaning; do not turn correction into style rewriting.
- Support claims about research or measured performance with a primary source or reproducible evidence.
- Do not claim an accuracy rate without a documented evaluation and dataset.

## Pull requests

Describe the user problem, the behavior change, and one example that demonstrates the result. Keep changes focused and update the README when installation or user-facing behavior changes.
